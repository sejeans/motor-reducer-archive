# 차량 안에서 판정하는 가벼운 고장 진단 모델

2026년 시스템설계 발표자료입니다. 자율주행 전기차의 모터와 감속기 고장을 차량 안의 작은 컴퓨터에서 판정하는 모델을 소개합니다.

## 보는 방법

- 웹: https://sejeans.github.io/motor-reducer-archive/
- 내려받아 보기: 저장소를 내려받은 뒤 `최종발표/발표_열기.html`을 Chrome이나 Edge로 엽니다. 인터넷 연결 없이 열립니다. `최종발표` 폴더만 따로 옮겨도 됩니다.

## 조작

| 키 | 동작 |
|---|---|
| `→`, Space, 클릭 | 다음 |
| `←` | 이전 |
| `S` | 슬라이드 목록 |
| `F` | 전체 화면 |
| `N` | 대본 보기 |
| `P` | 발표자 창 |
| 숫자 입력 후 `Enter` | 그 슬라이드로 이동 |
